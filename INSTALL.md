# Albion Market Scanner — инструкция по установке и настройке

## 1. Что должно быть на компьютере

- **Windows 10/11 (64-bit).** Приложение — один `.exe`, Python устанавливать не нужно.
- **Tesseract OCR 5.x** с языковыми пакетами **eng** и **rus**. Без него распознавание текста не работает.
- Два монитора / масштабирование Windows (125%, 150% и т.д.) поддерживаются, но см. раздел 5 про разрешение — это важно.

### Установка Tesseract OCR

Официальная сборка для Windows — проект UB-Mannheim (не какой-либо сторонний сайт).

```bash
winget install --id UB-Mannheim.TesseractOCR --accept-package-agreements --accept-source-agreements
```

Появится запрос на права администратора (UAC) — подтвердите.

По умолчанию ставится в `C:\Program Files\Tesseract-OCR\`. Проверить:

```bash
& "C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs
```

Должно быть в списке: `eng`, `osd`, `rus`. Если `rus` нет — скачайте файл языка отдельно (нужны права администратора на запись в `Program Files`, поэтому запускайте PowerShell **от имени администратора**):

```bash
Invoke-WebRequest -Uri "https://github.com/tesseract-ocr/tessdata/raw/main/rus.traineddata" -OutFile "C:\Program Files\Tesseract-OCR\tessdata\rus.traineddata"
```

Если Tesseract стоит не в стандартном месте — путь к `tesseract.exe` прописывается в настройках приложения (кнопка «Настройки» → «Основные» → «Путь к tesseract.exe»), файлы редактировать вручную не нужно.

## 2. Сборка `.exe` из исходников

Нужно только если у вас исходный код (например, из git-репозитория), а не уже готовый `AlbionMarketScanner.exe`.

1. Установите Python 3.11+, затем зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
2. Соберите один exe-файл (обязательно с `--add-data` для звука выстрела, иначе `.exe` соберётся без него):
   ```bash
   pyinstaller --onefile --windowed --name AlbionMarketScanner --add-data "assets/gunshot.wav;assets" main.py
   ```
3. Готовый файл появится в `dist\AlbionMarketScanner.exe`.
4. Скопируйте туда же `config.json` и `aliases.json` из корня проекта — сам `.exe` их не содержит (почему — см. раздел 3).

Если пересобираете поверх уже работающей версии — сначала закройте запущенный `AlbionMarketScanner.exe` (иначе PyInstaller не сможет перезаписать файл, будет `PermissionError`).

## 3. Файлы, которые должны лежать рядом с `AlbionMarketScanner.exe`

Приложение читает и сохраняет JSON-файлы **в той же папке, где лежит exe** (не внутри самого exe). Если их нет — создаются автоматически при первом запуске с настройками по умолчанию, но лучше знать, что это и за что отвечает:

| Файл | За что отвечает |
|---|---|
| `config.json` | хоткеи, путь к БД, путь к tesseract и т.д. |
| `aliases.json` | соответствие alias в скобках (например «знаток») → тир предмета |
| `enchant_colors.json` | эталонные HSV-цвета полосы зачарования (0-4), см. раздел 4 |
| `zones.json` | координаты трёх зон захвата — появляется после разметки, **свой на каждом ПК/мониторе** |
| `data.db` | сюда НЕ кладётся — база хранится отдельно, см. ниже |

Все эти файлы можно редактировать без блокнота — кнопками **«Настройки»** и **«Редактировать зоны»** в самом приложении.

### Текущие значения по умолчанию

`config.json`:
```json
{
  "hotkey_capture": "F8",
  "hotkey_edit_zones": "ctrl+F8",
  "db_path": "%LOCALAPPDATA%/AlbionMarketScanner/data.db",
  "tesseract_path": "C:/Program Files/Tesseract-OCR/tesseract.exe",
  "price_thousands_separator": ",",
  "report_output_dir": "./reports"
}
```

`aliases.json` (тиры 1-3 alias в игре не имеют, поэтому их здесь нет):
```json
{
  "знаток": 4,
  "эксперт": 5,
  "мастер": 6,
  "магистр": 7,
  "старейшина": 8
}
```

`enchant_colors.json` — эталонные цвета полосы зачарования, снятые с реальных скриншотов (не заглушки):
```json
{
  "0": {"h": 14.9, "s": 80.0, "v": 171.2},
  "1": {"h": 68.0, "s": 178.0, "v": 255.0},
  "2": {"h": 88.0, "s": 109.8, "v": 189.5},
  "3": {"h": 144.0, "s": 111.7, "v": 184.3},
  "4": {"h": 21.4, "s": 120.8, "v": 207.2}
}
```

### База данных (`data.db`)

Хранится **не рядом с exe**, а в:
```
%LOCALAPPDATA%\AlbionMarketScanner\data.db
```
Так она переживёт замену/обновление exe и не требует прав администратора на запись. Папка создаётся автоматически при первом захвате.

## 4. Первый запуск

1. Скопируйте `AlbionMarketScanner.exe` вместе с `config.json`, `aliases.json`, `enchant_colors.json` в отдельную папку (например `C:\Albion Scanner\`).
2. Запустите `AlbionMarketScanner.exe`.
3. Так как `zones.json` ещё нет — сразу откроется редактор зон. Разметьте по очереди три зоны, наведя на настоящий тултип предмета в игре:
   - **Название предмета** — вся строка, включая alias в скобках.
   - **Индикатор зачарования** — **сплошная цветная полоса** под рядом ромбиков-пипсов (не сами ромбики!). Зона должна попадать только на эту полосу, без ромбиков сверху и без соседних элементов.
   - **Цена продажи** — первая строка в «Заказы на продажу».
4. Нажмите «Сохранить».
5. В главном окне выберите класс предмета (Охотник/Маг/Воин).
6. Наведите на предмет в игре и нажмите **F8** — услышите звук выстрела и увидите результат распознавания.

## 5. Вопрос с разрешением экрана

Это важно понимать, иначе зоны будут «съезжать»:

- **Зоны привязаны к конкретному монитору, его разрешению и масштабу Windows (100%/125%/150%…) на момент разметки.** Если вы:
  - поменяли разрешение экрана,
  - поменяли масштаб (DPI) в настройках Windows,
  - переместили окно игры на другой монитор,
  - переустановили/перенесли приложение на другой ПК с другим монитором,

  — зоны нужно **разметить заново** (кнопка «Редактировать зоны» или хоткей `ctrl+F8`). Старые координаты работать не будут.

- Многомониторные системы с разным масштабом на каждом мониторе (например, один 125%, второй 100% — частый случай) поддерживаются корректно: при разметке приложение определяет, на каком именно мониторе вы рисуете зону, и её собственный масштаб, а не общий для всей системы.

- Рекомендация: играть в **оконном/полноэкранном-оконном режиме на фиксированном разрешении**, не переключать его между сессиями сканирования — тогда одна разметка зон будет работать стабильно долго.

## 6. Повседневное использование

- **F8** — захват (нужно: выбран класс + зоны настроены).
- **ctrl+F8** — открыть редактор зон.
- **«Редактировать БД»** — посмотреть/отфильтровать/удалить записи (поиск по части названия, без учёта регистра, например «мант» найдёт все «Мантии»).
- **«Настройки»** — все параметры из `config.json`/`aliases.json`/`enchant_colors.json` через интерфейс, без ручного редактирования файлов. Применяется сразу, перезапуск не нужен.
- **«Сформировать отчёт»** — Excel с 3 листами (Охотник/Маг/Воин), тиры 4-8 × зачарования 0-3, цветные заголовки.

## 7. Как определяется зачарование

Два метода, переключаются в «Настройках» → «Основные» → «Метод определения зачарования»:

**По цвету зоны (автоматически, по умолчанию).** Под ромбиками-пипсами есть **сплошная цветная полоса**, чей цвет однозначно соответствует уровню (0=бежевый, 1=зелёный, 2=голубой, 3=фиолетовый, 4=золотой). Программа сэмплирует доминирующий цвет размеченной зоны `item_enchant` и сравнивает с таблицей в `enchant_colors.json` (вкладка «Цвета зачарования» в «Настройках»).

Если распознавание ошибается, сначала проверьте: зона `item_enchant` должна попадать **только** на эту полосу, без ромбиков и без соседних элементов — тогда правки цветов обычно не требуются, они уже сняты с реальных скриншотов.

**Вручную (F1-F4).** Зона `item_enchant` не нужна вообще — при разметке зон её не будет в списке. Перед нажатием F8 (или в любой момент) нажмите F1/F2/F3/F4, чтобы задать текущее зачарование (0/1/2/3) — оно отображается в главном окне и используется при каждом следующем захвате, пока не переключите снова. Хоткеи F1-F4 глобальные и активны, только пока выбран этот метод (в режиме «По цвету» не перехватываются, чтобы не мешать игровым хоткеям).

## 8. Частые проблемы

| Симптом | Причина |
|---|---|
| В названии предмета — случайный текст/мусор | Зоны съехали (см. раздел 5) — переразметить |
| Тир всегда «?», нужна проверка | alias из тултипа нет в `aliases.json` — добавить через «Настройки» |
| Зачарование определяется неверно | Зона `item_enchant` захватывает не только цветную полосу (см. раздел 7) — переразметить точнее |
| F8 не реагирует | Зоны не настроены или класс не выбран — статус видно в главном окне |
| OCR вообще не работает | Tesseract не установлен или путь в настройках неверный |
